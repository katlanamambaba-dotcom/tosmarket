# TOS MARKET V11.0 — Ultimate Stable

Production-oriented digital marketplace with account/profile, catalog, cart, TRX checkout, orders, reviews, favorites, notifications, support tickets, operational admin center, coupon campaigns, inventory history and custom SVG visual system.

## Render
- Root Directory: blank when ROOT package contents are uploaded to repository root
- Build: `npm install`
- Start: `npm start`

Passwords are never exposed in admin; they remain bcrypt hashes. Never commit secrets or private keys.
