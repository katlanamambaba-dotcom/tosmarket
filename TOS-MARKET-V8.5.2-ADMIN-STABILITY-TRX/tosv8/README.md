# TOS MARKET V8.5.2

Yönetim paneli stabilizasyonu ve sipariş/müşteri yönetimi güncellemesi.

- Admin paneli ayrı `ADMIN_PATH` adresinden açılır.
- Admin panelinde siteyi gez iframe'i kaldırıldı; menüler SPA olarak panel içinde kalır.
- Yönetici paneli Türkçeleştirildi.
- Kullanıcı moderasyonu: aktif, askıda, engelli, çevrimiçi/çevrimdışı, profil görünürlüğü, bio ve moderasyon notu.
- Siparişlerde müşteri, e-posta, sipariş kalemleri, ödeme ve durum ayrıntıları görüntülenir.
- Eski deneme kayıtlarını silmek için Ayarlar içinden tek seferlik bakım işlemi bulunur. Kullanıcılar ve ürünler korunur.
- Yeni sipariş, ödeme, destek ve yorum kayıtları normal şekilde tutulmaya devam eder.

Render Root Directory mevcut GitHub yapısına göre: `TOS-MARKET-V8.5-ADMIN-CONTROL-ROOM-TRX/tosv8`
Build: `npm install`
Start: `npm start`
