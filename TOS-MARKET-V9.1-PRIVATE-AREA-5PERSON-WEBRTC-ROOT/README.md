# TOS MARKET V9.1

Stable account + private communication build.

- Login/register without email verification or password reset.
- Private user-to-user messages.
- Private Area with tabs for messages and calls.
- WebRTC group voice/video rooms, maximum 5 participants.
- Screen sharing and room text chat.
- Only active users with public profiles can create/join rooms.
- TRX/TRON payments preserved.
- Admin/order/support features preserved.

Render (ROOT ZIP): Root Directory blank, Build `npm install`, Start `npm start`.
